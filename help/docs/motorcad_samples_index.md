## 本地示例代码（克隆仓库内，优先使用）

- `help/repos/pymotorcad/examples/` —— 官方示例（Python 脚本）
  - `basics/` —— 基础：打开工程、变量读写、计算
  - `advanced/` —— 高级用法
  - `internal_scripting/` —— Motor-CAD 内部脚本
  - `adaptive_library/` —— Adaptive Templates 库
  - `links/`
- `help/repos/pymotorcad/samples/` —— 示例脚本仓库镜像（含 Adaptive template repository 与 General example repository）
- `help/repos/pymotorcad/tests/` —— 单测（大量 API 用法参考）

## 在线 Example scripts repository 内容

- Adaptive template：slot 材料属性设置、IM parallel tooth bar → tapered tooth bar 转换
- General：应力采样、区域边界峰值应力、Ansys Motion 力导出、SYNC 电机参数扫描
