## 一、需要哪些参数

搭 e11 的 FOC + MTPA + 弱磁控制模型，需要的参数分四类：

| 类别 | 参数 | 来源 | 用途 |
|---|---|---|---|
| **电机本体** | 极对数 p | `.mot:6571` | 电角度换算 |
| | 永磁磁链 λpm | ECE 磁链表 | 转矩公式、基速 |
| | d/q 轴电感 Ld、Lq | ECE 磁链表（随电流变） | MTPA、电流环增益 |
| | 相电阻 Rs | ECE 导出（65 ℃） | 电流环增益、压降 |
| | 惯量 J、摩擦 B | **未获取**，需实测或从 CAD 估 | 速度环增益 |
| **电源** | 母线电压 Vdc | `.mot:5796` | 电压约束 |
| | 峰值电流 Imax | `.mot:5780` | 电流约束 |
| | PWM 频率 | **未定**，暂取 20 kHz | 采样率、增益标定 |
| **控制** | 电流环带宽 | **设计选择**，暂取 1000 Hz | PI 增益 |
| | 速度环带宽 | **设计选择**，暂取 30 Hz | PI 增益 |
| **标幺** | V_base、I_base | 由上面推导 | MTPA 模块单位 |

## 二、从 ECE 数据反推电感（关键步骤）

### 为什么不能直接用 MAT 里的 `Ld` / `Lq` 字段

实测发现两个问题：

1. **零电流处是除零产物**：`Ld[Id=0,Iq=0] = -7.4e13`，`Lq` 同理
2. **量纲与 `varUnits` 标称不符**：`varUnits[13]/[14]` 标 `mH`，但数值与磁链反推结果差 1000 倍

所以**一律由磁链反推**。

### 反推公式

由定义：

```
λd = Ld·id + λpm
λq = Lq·iq
```

在两个截面上取点：

| 截面 | 条件 | 求法 |
|---|---|---|
| Iq = 0 | 只有 d 轴电流 | `Ld = (λd − λpm) / id`，其中 `λpm = λd(id=0, iq=0)` |
| Id = 0 | 只有 q 轴电流 | `Lq = λq / iq` |

### 取哪个电流点

电感随电流饱和，必须说明取点。**MTPA 工作点大约在 0.7·Imax**，故：

- **额定点电感**：取 `|I| = 0.7 × 433 = 303 A` 处
- **饱和端电感**：取 `|I| = 433 A` 处

e11 实测（61×61 网格的 Iq=0 / Id=0 截面）：

| Id (A) | λd (Wb) | Ld (µH) | | Iq (A) | λq (Wb) | Lq (µH) |
|---|---|---|---|---|---|---|
| −433 | −0.02209 | **226.3** | | −433 | −0.12877 | **297.4** |
| −288.7 | 0.00883 | 232.3 | | −288.7 | −0.11415 | 395.4 |
| −72.2 | 0.05849 | 241.0 | | −72.2 | −0.04726 | **654.9** |
| +72.2 | 0.09315 | 239.3 | | +72.2 | 0.04727 | 655.0 |
| +433 | 0.14575 | **161.3** | | +433 | 0.12875 | 297.3 |

**关键观察**：

- **Ld 基本恒定**（161–241 µH），饱和影响小
- **Lq 变化剧烈**（297–655 µH），饱和影响大
- 这是 IPM 的典型特征：q 轴磁路主要走铁芯，容易饱和；d 轴被磁钢"堵住"，本身磁阻就大

### 取定值

| 量 | 额定点（0.7·Imax） | 饱和端（Imax） |
|---|---|---|
| λpm | **0.075883 Wb** | — |
| Ld | **231.8 µH** | 226.3 µH |
| Lq | **382.7 µH** | 297.4 µH |
| 凸极率 Lq/Ld | **1.65** | 1.31 |

> ⚠️ **一个已修正的错误**：早期版本取「|I| > 0.2·Imax 的平均值」，
> 把轻载的 655 µH 与满载的 297 µH 混在一起平均，算出凸极率 2.01（偏高）。
> 现已改为按工作点取点。

## 三、SVPWM 电压上限

```
Vmax = Vdc / √3 = 400 / 1.732 = 230.94 V
```

这是**相电压峰值**。注意不是 `Vdc/√3 × √2`——多乘 √2 会让基速算高 41%。

依据：`help/docs/mathworks/zh/06-per-unit-system.md`（MathWorks 明确定义 SVM 的 `V_base = Vdc/√3`）。

## 四、MTPA 解析解

### 公式

MathWorks 的 IPMSM MTPA（`11-mtpa-control-reference.md` §Interior PMSM）：

```
im = Imax

id_mtpa = λpm/(4(Lq−Ld)) − sqrt( λpm²/(16(Lq−Ld)²) + Imax²/2 )
iq_mtpa = sqrt( Imax² − id_mtpa² )
```

### 代入（额定点电感）

```
Lq − Ld = 382.7 − 231.8 = 150.9 µH = 1.509e-4 H

λpm/(4(Lq−Ld))       = 0.075883 / (4 × 1.509e-4) = 125.7
λpm²/(16(Lq−Ld)²)    = 0.075883² / (16 × 1.509e-4²) = 15800
Imax²/2              = 433² / 2 = 93744.5
sqrt(15800 + 93744.5) = 331.0

id_mtpa = 125.7 − 331.0 = −205.3 A
iq_mtpa = sqrt(433² − 205.3²) = 381.2 A
```

### 转矩

```
Te = 1.5 · p · [ λpm·iq + (Ld − Lq)·id·iq ]
   = 1.5 · 4 · [ 0.075883 × 381.24 + (231.8 − 382.7)e-6 × (−205.29) × 381.24 ]
   = 6 · [ 28.93 + 11.80 ]
   = 6 × 40.73 = 244.5 N·m
```

### 对照：id = 0 控制

```
Te(id=0) = 1.5 · 4 · 0.075883 × 433 = 197.1 N·m
```

**MTPA 增益 = 244.5 / 197.1 − 1 = 24.0%**

## 五、网格式独立验证

解析式假设电感恒定，而 e11 是饱和电机。用 ECE 网格（6 万+ 个点）暴力搜最优，做交叉验证：

| 方法 | MTPA 最优点 | 转矩 |
|---|---|---|
| 解析式（额定点电感） | Id=−205.3, Iq=381.2 | 244.5 N·m |
| **网格实测（61×61）** | **Id=−303.1, Iq=303.1** | **246.4 N·m** |

**转矩差 0.8%** —— 说明解析式可用作快速估算，但**工作点位置差很多**（Id 差 98 A）。
原因是工作点处 Lq 已饱和（382→297 µH），解析式的恒定电感假设此时不成立。

> **结论**：MTPA 工作点必须用**查表**（`16-fwc-mtpa-nonlinear-pmsm-lut.md` 的方案），
> 解析式只用于估算转矩上限。

## 六、基速

### 公式

```
ωbase = Vmax / |λ| / p
|λ|   = sqrt( (Ld·id + λpm)² + (Lq·iq)² )
```

### 代入（MTPA 点）

```
λd = 231.8e-6 × (−205.29) + 0.075883 = 0.02831 Wb
λq = 382.7e-6 × 381.24 = 0.14590 Wb
|λ| = sqrt(0.02831² + 0.14590²) = 0.1486 Wb

ωbase = 230.94 / 0.1486 / 4 = 388.5 rad/s（电角速度）
n_base = 388.5 / 4 × 60 / (2π) = 3404 rpm
```

### 与网格实测对照

网格搜出的各转速可达最大转矩（含电压约束）：

| 转速 | 可达转矩 | 工作点 (Id, Iq) | 说明 |
|---|---|---|---|
| 3000 rpm | 246.4 N·m | −303.1, 303.1 | 恒转矩区 |
| 4000 rpm | 246.4 N·m | −303.1, 303.1 | **仍在恒转矩区** |
| 5000 rpm | 231.5 N·m | −360.8, 230.9 | 已进弱磁 |
| 6000 rpm | 194.6 N·m | −389.7, 173.2 | 弱磁 |
| 8000 rpm | 153.7 N·m | −404.1, 129.9 | 深度弱磁 |
| 10000 rpm | 106.4 N·m | −418.6, 86.6 | 接近 MTPV |

**基速在 4000–5000 rpm 之间**，与解析式算的 3404 rpm 有差距。
原因是解析式用额定点电感，而实际工作点处 Lq 已饱和、λq 更小，基速更高。

**取工程值：基速约 4500 rpm**（保守），6,000 rpm 起进入弱磁区。

## 七、控制参数

### 采样率

参照 MATLAB 示例 `mcb_pmsm_fwc_qep_f28379d_data.m`：

```
PWM 频率     = 20 kHz
Ts（电流环） = 50 µs（= 1/20kHz，每开关周期算一次）
Ts_speed     = 30 × Ts = 1500 µs（速度环每 30 个电流周期算一次）
```

> ⚠️ PWM 频率是**设计选择**，不是 e11 的固有参数。`.mot` 里的 100 kHz 是损耗等效值，
> 不能当开关频率用。20 kHz 是与 TI 样板一致的起点，实际须按功率级方案定。

### 电流环 PI 增益

整定规则：**零极点对消 + 期望带宽**

```
Kp = ωc · L
Ki = ωc · R
ωc = 2π · f_bw
```

理由：电流环被控对象是 `1/(Ls + R)`，PI 传函 `Kp + Ki/s`。
令 `Ki/Kp = R/L` 对消掉电路极点，开环变成 `Kp/(Ls)`，是纯积分器，
闭环带宽即 `Kp/L = ωc`。

取 `f_bw = 1000 Hz`（开关频率的 1/20，留足稳定裕度）：

```
ωc = 2π × 1000 = 6283 rad/s

Kp_d = 6283 × 231.8e-6 = 1.4562
Ki_d = 6283 × 0.013377  = 84.05
Kp_q = 6283 × 382.7e-6  = 2.4046
Ki_q = 6283 × 0.013377  = 84.05   （与 d 轴相同，因为都补偿 Rs）
```

> ⚠️ **Lq 的取值影响 Kp_q**：用额定点 382.7 µH 得 Kp_q=2.40；
> 若用饱和端 297.4 µH 得 Kp_q=1.87。建议按**额定工作点**整定，再用 Autotuner 在弱磁段复核。

### 速度环 PI 增益

```
Kp_s = J · ωs
Ki_s = Kp_s · ωs / 5
ωs = 2π · f_bw_speed
```

取 `f_bw_speed = 30 Hz`（电流环的 1/33，满足级联环 5–10 倍分离要求）：

```
ωs = 2π × 30 = 188.5 rad/s
J  = 0.01 kg·m²（⚠️ 占位值，需实测）
Kp_s = 0.01 × 188.5 = 1.885
Ki_s = 1.885 × 188.5 / 5 = 71.06
```

> ⚠️ **惯量 J 是占位值**。`.mot` 里没有可直接读出的转动惯量，
> 需要从转子几何算或实测。J 错 10 倍，速度环增益就错 10 倍。

## 九、还缺的参数

| 参数 | 为什么缺 | 怎么补 |
|---|---|---|
| **转动惯量 J** | `.mot` 无此字段 | 从转子几何（130 mm 直径、260 mm 长、硅钢+磁钢）估算，或实测自由停机曲线 |
| **摩擦系数 B** | 同上 | 停机试验拟合 |
| **实际 PWM 频率** | 功率级未定 | 由逆变器方案决定；目前按 20 kHz 占位 |
| **电流采样量程 I_base** | 逆变器未选 | 决定标幺基准；不能用电机 433 A 硬套 |
| 额定转矩 / 额定电流 | `.mot` 的 4 个负载点都是 40 N·m（模板算例） | 按热约束另行确定 |

## 十、复算方法

```powershell
# 换数据源（例如 91×91 完成后）重算
& 'C:\Env\miniconda3\envs\pmsm\python.exe' scripts/calc_control_params.py `
    --mat results/e11-ece-91x91/ECE_e11_91x91_map.mat `
    --json-out results/e11-control-params.json

# 改带宽重算
--current-bw 1500 --speed-bw 50

# 改 PWM 频率
--pwm-hz 10000
```

脚本会打印每一步的公式与代入值，便于人工复核。
