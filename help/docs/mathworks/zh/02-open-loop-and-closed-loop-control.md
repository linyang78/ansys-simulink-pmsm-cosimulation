## 概述

**开环控制**（也称标量控制或 Volts/Hz 控制）：控制器不使用输出反馈来运行交流电机。
**闭环控制**：控制器实时监测电机实际转速、转矩与位置，并调整控制信号。

两种技术各有优缺点，适用于不同场景。

---

## 开环控制

开环控制用输入的参考机械转速确定参考定子电压频率 fref 与参考电压幅值 Vref。
由于不用任何反馈，它无法对控制量做实时调整。

它不依赖被控对象的实时位置反馈，而是由控制输入推算电角度位置。
系统再用该位置与参考电压值生成电机相电压。

适用于动态响应要求不高、追求低成本的场合。
开环控制无法考虑影响转速的外部条件，因此不能自动纠正期望转速与实际转速之间的偏差。

开环系统的功率回路是「直流电源 + PWM 电压型逆变器」，不使用任何反馈信号，
由参考转速决定定子电压的频率。

> [图：开环控制系统框图]

### 磁链恒定原理

系统让电压幅值正比于「额定电压 / 额定频率」之比（即 **Volts/Hz 比**），从而保持磁链恒定：

```
λm ∝ Vs / fs
```

- λm：电机额定磁链（Wb）
- Vs：定子电压（V）
- fs：定子电压与电流频率（Hz）

### 转速与频率

```
Speed(rpm) = 60 × fs / p
fref = p × RPMref / 60
```

- p：极对数
- RPMref：要求的参考转速

### 电压幅值

维持磁链等于额定磁链，即维持额定电压与额定频率之比恒定：

```
ψm_rated ∝ Vrated / frated
Vref = (Vrated / frated) × fref
```

开环系统用 fref、Vref 与推算出的电角度位置生成逆变器 PWM 占空比。
三相电压波形保持 Vref/fref 之比恒定，即可让定子磁链相对恒定。

但 V/F 比并非在整个转速范围内都恒定：

- **A 区（低速）**：需要最低升压电压（额定电压的 15% 或 25%）来抵消定子电阻压降，Vmin 即为该补偿
- **B 区（恒 V/F）**：保持 Vrated/frated 之比恒定，按 fref 算 Vref
- **C 区（高速）**：定子电压已到 Vrated 上限，V/F 比无法维持，Vref 保持在 Vrated 不再上升

以额定磁链运行可避免电机过热，并通过平衡输出转矩与消耗功率提高效率。
除简化算法外，额定磁链还让电机行为更可预测。

### 局限

开环系统不评估、不修正影响转速的内外部扰动（如负载变化），
因此无法自动纠正期望转速与实际转速之间的偏差。

**注意：** 这里描述的开环实现**不补偿定子电阻压降，也不做弱磁**。

### 标幺制注意

用标幺制表示时，开环控制把 Vrated 作为基准量，通常对应 1PU 或 100% 占空比。
（若用正弦 PWM 而非空间矢量 PWM，还需额外乘以 2/3 的增益。）详见《标幺制》。

关于开环运行三相电机的示例，见《Run 3-Phase AC Motors in Open-Loop Control and Calibrate ADC Offset》。

## 闭环控制

闭环控制用实时反馈（电流、机械位置）把参考输入与实际输出（转速、转矩或位置）比较，
再对参考电压与占空比做必要修正，把误差降到最小，使电机输出匹配参考输入。

借助实时反馈，闭环系统可对转速、位置或转矩做精确控制。
与开环不同，闭环会自动补偿内外部扰动（如负载变化）。
可用控制参数（控制器增益）来整定并优化系统的响应性、准确度与稳定性。

适用于精度、适应性、效率要求高的场合，如机器人、无人机、电动车、工业自动化。

### 四个关键部件

- **电机**：被控对象，如 PMSM 或 AC 感应电机（ACIM）
- **传感器**：测实际输出。正交编码器、旋变、霍尔测转子机械位置；
  模数转换器（ADC）测相电流并给出数字量
- **控制器**：处理传感器输出、与输入比较、调整控制信号
- **逆变器/驱动器**：把控制信号转成三相电压驱动电机

### 五个步骤

任何闭环控制技术都按这五步循环：

1. **设定目标**：给出期望的转速、转矩或位置
2. **测反馈**：用传感器或无传感器算法测位置与相电流
3. **比较**：反馈与目标相减得误差
4. **修正**：由误差算出控制信号调整量
5. **执行**：调整后的信号改变相电压，使输出匹配目标

## 矢量控制

矢量控制（d-q 电流控制）是控制三相交流电机的常用闭环电流控制技术。
先用 **Clarke 变换**把三相电流转到 α-β 静止参考系，
再用 **Park 变换**把电流转到旋转 d-q 参考系，此时电流由 **DC 信号**表示。

直接用 PI 控制相电流（交流量）会因增益受限而响应滞后。

而用 d-q 等效量（直流量）可显著提高 PI 的控制效率与性能。
因为积分控制能带来最小稳态误差与极高 DC 增益，
**PI 控制器控制直流信号时效率非常高**。

矢量控制利用这一效率：用 PI 控制 d-q 轴电流（控制输入），
生成零稳态误差的 d-q 轴电压（控制信号）；
再用数学变换把电压转成逆变器占空比，由逆变器输出对应三相电压驱动电机。

矢量控制算法保证旋转 d-q 参考系与三相对称定子电压**同步**，频率与位置都一致。

> [图：矢量控制的总体原理；实现矢量控制的建模方法]

算法用两个 PI 控制器分别独立控制 d 轴与 q 轴电流，输出 d-q 轴电压作为控制信号；
再用逆 Park 变换把电压转成静止正交参考系下的 α 轴、β 轴分量；
最后用 PWM 等调制技术由这些电压生成占空比驱动逆变器。

把电流变到 d-q 轴需要转子机械位置反馈，可用位置传感器或无传感器位置估计器获得。

算法中可用采样延迟模拟电流测量期间的滞后，
同样可用延迟模拟执行控制算法所需的计算时间。

为获得准确结果，必须适当整定 PI 增益。
关于 Motor Control Blockset™ 提供的整定方案，见《增益计算与整定》。

## 开环到闭环的切换

某些应用需要先开环起动，等电机达到最低稳定要求后再切到闭环。

用正交编码器测位置时，电机开环起动，检测到**索引脉冲（index pulse）**后切到闭环。

无传感器位置控制中，电机先在开环下运行到基速的 10%；
参考值超过基速 10% 后从开环切到闭环。
为保证切换平滑，PI 控制器要**复位并从与开环输出相同的初始条件开始**。
